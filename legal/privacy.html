Schedule Manager — Privacy Policy

Last updated: 2026-09-02

Who operates this application

Schedule Manager is a personal tool built and operated by one individual for their own use. It is not offered as a service, has no other users, and is not available for sign-up.

What data the application accesses

Using the https://www.googleapis.com/auth/gmail.readonly scope, the application reads messages from a single Gmail account created solely for this purpose. This scope is read-only: the application cannot send, modify, label, or delete mail, and it requests no other Google API scope.

Why it accesses that data

Schedules, deadlines, and job postings arrive by email from several sources. The application collects them into one private personal view so they do not have to be copied by hand.

Who can see the data

Only the operator. Collected data is stored in a private database on infrastructure the operator controls. It is not shared with any third party, not sold, not used for advertising, and not used to train any machine-learning model.

How long the data is kept

Original message content is deleted 90 days after collection. A minimal record — such as a title, a date, and a link — may be retained for longer so that past items remain searchable.

Revoking access

Access granted to this application can be withdrawn at any time at myaccount.google.com/permissions. Revoking access immediately stops all further collection.

Changes to this policy

If this policy changes, the revised version replaces this page and the date above is updated.

Contact

Questions about this policy can be raised at the project's issue tracker.
